# Accessibility

Target WCAG 2.2 AA pada jalur utama.

- lang=id; landmark semantik; satu h1; urutan heading.
- Skip link, fokus terlihat, target >=44px, kontras teks >=4.5:1.
- Filter button aria-pressed; hasil status sopan; tautan detail tetap tanpa JS.
- Menu aria-expanded/controls; Escape menutup, fokus kembali.
- Dialog native modal, focus containment, label, tutup/Escape/panah, posisi, focus return.
- Foto alt deskriptif; dekorasi aria-hidden; kegagalan diberi teks.
- Informasi tidak hanya warna/hover; reduced motion dan lebar 320px.

Verifikasi keyboard/fokus, axe beranda/detail/404, viewport 320/390/768/1440. Audit otomatis bukan pengganti pembaca layar manual. Hasil aktual di progress.md.
